# PokeMon_classification_using_CNN
Pokémon dataset contains 150 different Pokémon classes.
We developed a CNN model to precisely categorize Pokémon photos into the appropriate species. The objective is to use each Pokémon's unique visual traits to construct a strong image classification system that can accurately distinguish between various Pokémon species.

* Download Pokemon Date from ( "!kaggle datasets download -d lantian773030/pokemonclassification")
* Unzip the Pokémon data.
* Detailed Comments are given in the ".ipynb" file.
* Create a new conda env using "conda create -n pokemon python==3.8"
* Then run "!pip install -r requirements.txt"
